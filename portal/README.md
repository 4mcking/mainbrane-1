# the hive portal

the rooms live in this folder. the readme at the root of the github repo stays the profile page for github.com/mainbrane.

```bash
cd portal
npm install
npm run dev
```

then open the url the server prints.

`npm run build` then `npm start` for a production run. netlify can build this folder with `portal` as the base, or `npm run build` from inside it.
